Willkommen zu SaarCarLux!

## Beschreibung
SaarCarLux ist eine Autohändler Website die mit Umbraco CMS entwickelt wurde. Besucher dieser Website können hier verschiedene Autos ansehen and kurz informationen aufrufen.

Das Projekt demonstriert die Verwendung von Umbraco Content Management, Document Types, Templates, CSS sowie auch HTML.


## Funktionen
- Startseite
- Dynamische Anzeige von Autos
- Fahrzeugbilder durch Umbraco Media Picker
- Autos und deren Details
- Navigation zwischen Home, Cars, About und Contact


## Umbraco Struktur
### Document Types
- Home
- CarDealerShip

### Eigenschaften von CarDealerShip
- CarName
- Brand
- Model
- CarImage
- Year
- Price
